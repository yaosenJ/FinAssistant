# 约束与边界

## 任务边界

### 分析范围
- 仅分析组委会指定的49只上市公司
- 不得分析列表外的股票
- 仅使用已入库的历史财务数据，不调用外部实时API

### 决策约束
- 单只股票最大仓位不超过20%
- 综合评分低于40分的股票不得入选组合
- 异常检测为"回避"级别的股票不得入选
- 权重之和必须等于1.0（或1.0-现金比例）

### 输出约束
- Portfolio.json 使用6位纯数字代码（无后缀）
- 研报必须包含风险提示声明
- 所有数据必须注明来源和报告期

## 失败处理

| 失败场景 | 处理方式 |
|---------|---------|
| 某只股票财务数据缺失 | 该维度评分设为基准分50，标注数据不足 |
| 某只股票K线数据不足 | 技术面评分设为50，标注数据不足 |
| 异常检测脚本报错 | 异常检测评分设为80（默认安全），标注检测失败 |
| 所有股票评分均为0 | 输出空组合，说明无可选标的 |
| 评分计算溢出 | 截断到0-100范围 |

## 资源限制

- 单次分析总耗时不超过10分钟
- Token消耗不超过基线Agent的1.5倍
- 并发分析股票数不超过49只
