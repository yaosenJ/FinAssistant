# 财务异常检测技能

## When to Use
- "XX有没有财务风险"
- "XX有没有暴雷风险"
- "检查XX的财务异常指标"
- 选股排雷筛选时

## Execution Steps

### Step 1: 运行异常检测
```bash
python scripts/anomaly_detection.py --ts_code {ts_code}
```

### Step 2: 检测7类异常

| 异常类型 | 检测逻辑 | 高风险阈值 |
|---------|----------|-----------|
| 经营现金流骤降 | 净利润正但现金流负 | 现金流<-50%净利润 |
| 应收账款激增 | 增速>营收增速2倍 | 增速>80% |
| 商誉减值风险 | 商誉/净资产比例 | >30% |
| 存货异常增长 | 增速>营收增速2倍 | 增速>80% |
| 负债率飙升 | 短期上升幅度 | >20个百分点 |
| 利润现金流背离 | 连续多期正利润负现金流 | >=2期 |
| 毛利率异常波动 | 下降幅度 | >20个百分点 |

### Step 3: 风险评级
- 无异常: 安全
- 1-2个中风险: 关注
- 1个高风险: 警惕
- 2+高风险: 回避
