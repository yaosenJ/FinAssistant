# JiuwenSwarm 框架优化说明

## 一、修改概述

本项目对 JiuwenSwarm 框架进行了深度扩展，新增了 **7 个金融分析 Skill**（6 个 Single Skill + 1 个 Swarm Skill），使框架具备完整的 A 股量化分析能力。

### 修改类型

- **新增文件**：7 个 Skill 目录，共 21 个文件（SKILL.md × 7、Python 脚本 × 6、角色定义 × 5、工作流 × 1、约束 × 1、依赖 × 1）
- **修改文件**：`.gitignore` — 添加 Skill 目录的 git 追踪例外规则

### 修改位置

```
D:\jiuwenswarm\jiuwenswarm\resources\agent\workspace\skills\
├── stock-fundamental-analysis/    [新增] 基本面分析 Skill
├── stock-valuation-analysis/      [新增] 估值分析 Skill
├── stock-technical-analysis/      [新增] 技术面分析 Skill
├── financial-anomaly-detection/   [新增] 异常检测 Skill
├── portfolio-construction/        [新增] 组合构建 Skill
├── investment-report-generation/  [新增] 研报生成 Skill
└── financial-analysis-team/       [新增] Swarm Skill（5角色协作）
```

## 二、新增 Skill 详细说明

### 2.1 Single Skills（6个）

#### stock-fundamental-analysis（基本面分析）

- **功能**：计算 ROE、毛利率、净利率、资产负债率、经营现金流/净利润比、营收/净利润增长率
- **脚本**：`scripts/fundamental_analysis.py`，调用 `tools.stock_fundamental.calc_fundamental_indicators`
- **输出**：Markdown 表格 + JSON 结构化数据

#### stock-valuation-analysis（估值分析）

- **功能**：计算 PE_TTM 和 PB 的历史分位数（近1年），判断估值水平
- **脚本**：`scripts/valuation_analysis.py`，调用 `tools.stock_valuation.calc_valuation_percentile`
- **输出**：估值指标表（当前值、分位数、估值水平、1年最低/最高/均值）

#### stock-technical-analysis（技术面分析）

- **功能**：计算 MA(5/10/20/60)、MACD(DIF/DEA)、RSI(6/12/24)、KDJ(K/D/J)
- **脚本**：`scripts/technical_analysis.py`，调用 `tools.stock_technical.calc_technical_indicators`
- **输出**：技术指标表 + 买卖信号

#### financial-anomaly-detection（异常检测）

- **功能**：7 类财务异常检测（现金流骤降、应收账款激增、商誉减值、存货激增、负债率飙升、利润-现金流背离、毛利率异常波动）
- **脚本**：`scripts/anomaly_detection.py`，调用 `tools.financial_anomaly.detect_anomalies`
- **输出**：异常列表（类型、严重程度、数据、说明）+ 风险评级

#### portfolio-construction（组合构建）

- **功能**：基于评分结果生成投资组合，支持评分加权、仓位上限、现金比例
- **脚本**：`scripts/portfolio_builder.py`，调用 `competition.portfolio_builder.build_portfolio`
- **输出**：Portfolio.json（6位代码: 权重）

#### investment-report-generation（研报生成）

- **功能**：为入选股票生成 Markdown 格式研究报告，涵盖基本面、估值、技术面、风险检测
- **脚本**：`scripts/report_generator.py`，调用 `competition.report_generator.generate_stock_report`
- **输出**：个股研究报告 .md 文件

### 2.2 Swarm Skill（1个）

#### financial-analysis-team（金融分析团队）

- **类型**：`kind: team-skill`（团队协作 Skill）
- **角色定义**（5个）：
  - `coordinator` — 协调者：任务分解、团队调度、结果聚合、组合构建
  - `fundamental-analyst` — 基本面分析师：ROE/毛利率/现金流/成长性分析
  - `valuation-analyst` — 估值分析师：PE/PB 历史分位数分析
  - `technical-analyst` — 技术面分析师：MA/MACD/RSI/KDJ 技术指标分析
  - `risk-manager` — 风险管理者：7 类财务异常检测 + 风险评级

- **协作流程**（workflow.md）：
  ```
  4个分析师并行分析 → 评分汇总 → 组合构建 → 研报生成
  ```

- **约束条件**（bind.md）：
  - 单只股票最大仓位 ≤ 20%
  - 综合评分 < 40 分不得入选
  - 异常检测"回避"级别不得入选
  - 权重之和 = 1.0

- **依赖声明**（dependencies.yaml）：
  - 依赖 6 个 Single Skill
  - 依赖 `executeCommand`、`readFile`、`writeFile` 工具
  - 需要 Python >= 3.9、pymysql、python-dotenv

## 三、与原框架的兼容性

### 3.1 向后兼容

- 所有新增 Skill 均遵循 JiuwenSwarm 的 YAML frontmatter 规范
- SKILL.md 格式与现有 Skill 保持一致（name、description、version、tags、allowed_tools）
- Swarm Skill 遵循 5 文件规范（SKILL.md、roles/*.md、workflow.md、bind.md、dependencies.yaml）

### 3.2 不影响现有功能

- 新增 Skill 不修改任何现有 JiuwenSwarm Python 代码
- 不改变框架的 Skill 加载机制
- 不影响现有 Skill 的运行

### 3.3 扩展性

- 每个 Skill 独立可运行，可通过 Symphony 自由编排
- Swarm Skill 可被 JiuwenSwarm 的团队协作机制直接调度
- 脚本通过 `sys.path` 动态导入，不硬编码路径

## 四、安装方式

```bash

# 手动安装（等效操作）
cp -r competition/jiuwenswarm-skills/* D:\jiuwenswarm\jiuwenswarm\resources\agent\workspace\skills\
```
