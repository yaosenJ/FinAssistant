# 跨数据关联分析技能

## 触发条件

用户询问个股-板块归属、板块财务估值、新闻-行情关联时触发。典型问题：

**个股归属查询**：
- "贵州茅台属于哪些板块？"
- "宁德时代在哪些概念板块里？"
- "比亚迪所属板块最近表现如何？"

**板块财务查询**：
- "白酒板块的ROE和毛利率水平如何？"
- "半导体板块的估值分布是怎样的？"
- "银行板块和证券板块谁的盈利能力更强？"

**新闻关联查询**：
- "最近有关于光伏的新闻吗？"
- "贵州茅台最近有什么利好消息？"
- "半导体板块近期有哪些新闻？相关个股走势如何？"

**综合关联分析**：
- "茅台最近有什么利好新闻？它所在板块表现如何？"
- "最近新能源板块有什么消息？板块财务状况怎么样？"
- "找出和宁德时代关联度最高的板块，分析板块估值"

## 依赖工具组

| 工具组 | 包含工具 | 功能 |
|--------|----------|------|
| `stock-sector` | find_stock_sectors | 个股-板块映射：查询个股所属板块及近期表现 |
| `sector-finance` | get_sector_financial_agg, get_sector_valuation_stats | 板块财务分析：财务聚合、估值分布 |
| `news-market` | find_news_by_keyword, search_news_with_market | 新闻-行情关联：新闻搜索、新闻与行情联动分析 |

## 输入参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ts_code` | str | 视情况 | 股票代码（带后缀），如 600519.SH |
| `sector_name` | str | 视情况 | 板块名称，支持模糊匹配 |
| `sector_type` | str | 否 | 板块类型：industry(行业) / concept(概念)，默认 industry |
| `keyword` | str | 视情况 | 新闻搜索关键词 |
| `limit` | int | 否 | 返回条数，默认 5-10 |

## 工具调用策略

### 问题 → 工具映射

| 用户问题类型 | 首选工具 | 补充工具 |
|-------------|---------|---------|
| "XX属于哪些板块" | find_stock_sectors | - |
| "XX板块财务如何" | get_sector_financial_agg | get_sector_valuation_stats |
| "XX板块估值分布" | get_sector_valuation_stats | - |
| "最近XX有什么新闻" | find_news_by_keyword | search_news_with_market |
| "XX新闻+行情关联" | search_news_with_market | - |
| "XX利好新闻+板块表现" | find_stock_sectors → search_news_with_market | get_sector_financial_agg |

### 复合问题处理

对于综合关联分析问题（如"茅台最近有什么利好新闻？它所在板块表现如何？"），按以下顺序调用：

1. 先调用 `find_stock_sectors` 获取个股所属板块
2. 再调用 `search_news_with_market` 搜索新闻并关联行情
3. 最后调用 `get_sector_financial_agg` 分析板块财务状况

## 分析框架

### 关联分析维度

| 维度 | 分析内容 | 数据来源 |
|------|---------|---------|
| 个股→板块 | 个股所属行业/概念板块，板块近期涨跌 | stock_sector_mapping |
| 板块→财务 | 板块整体ROE、毛利率、营收、估值水平 | sector_financial_agg |
| 新闻→行情 | 新闻标题匹配个股/板块，关联前后行情走势 | news_stock_linker |
| 综合研判 | 交叉分析：新闻利好+板块估值+资金流向 | 多工具组合 |

### 估值水平判断

| PE百分位 | 水平 | 说明 |
|---------|------|------|
| <20% | 低估 | 板块内估值处于低位 |
| 20%-40% | 合理偏低 | 估值略低于中位水平 |
| 40%-60% | 合理 | 估值处于中位水平 |
| 60%-80% | 合理偏高 | 估值略高于中位水平 |
| >80% | 高估 | 板块内估值处于高位 |

## 注意事项

1. **代码格式**：股票代码需带后缀（如 600519.SH），板块名称支持模糊匹配
2. **板块类型**：行业板块和概念板块分开查询，默认行业板块
3. **新闻匹配**：基于标题关键词匹配，非 NER 实体识别，匹配精度有限
4. **数据时效**：财务数据基于最新报表期，行情数据基于最新交易日
5. **免责声明**：所有分析仅供参考，不构成投资建议
